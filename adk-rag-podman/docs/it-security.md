# Acme Corp IT Security Guidelines (sample data)

## Passwords
Passwords must be at least 14 characters and are rotated every 180 days. Multi-factor authentication is mandatory for email, VPN and cloud consoles.

## Lost devices
Report a lost laptop or phone to the IT helpdesk at extension 4040 within 2 hours. IT will remotely lock and wipe the device.

## Software installation
Only software from the internal software catalogue may be installed. Requests for new tools go through a ticket to the security team, with a typical approval time of 3 working days.
